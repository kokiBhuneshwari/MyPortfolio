


# Personal Portfolio Website

## 📌 About the Project

This is my personal portfolio website, developed using **HTML5 and CSS3**. The purpose of this project is to showcase my skills, projects, educational background, and personal information in a clean and professional layout.

The portfolio is designed with a simple, attractive, and user-friendly interface to provide visitors with an overview of my technical abilities and development journey.

## 🚀 Technologies Used

- **HTML5** – Used to structure the web pages and organize content.
- **CSS3** – Used for styling, layouts, colors, animations, and responsive design.

## ✨ Features

- Clean and modern user interface.
- Navigation bar for easy navigation.
- About Me section.
- Skills and technologies section.
- Projects showcase.
- Contact information section.
- Responsive layout for different screen sizes.
- Attractive styling using CSS.

## 🎯 Project Objectives

- Improve my HTML and CSS fundamentals.
- Understand webpage structure and layout design.
- Practice Flexbox and CSS positioning.
- Learn how to create reusable and maintainable styles.
- Build a personal online presence to showcase my work.

## 💻 How to Run the Project

1. Clone this repository:

   ```bash
   https://github.com/kokiBhuneshwari/MyPortfolio.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.
